# User Nickname BepInEx Plugin for the SPTvP Modification

## Overview

- Part of the overall SPTvP modification for SP-Tushonka
- Player downloaded plugin
- Ties the username of a user in https://sptvp.org to communitiy profiles

## Specifics

**Profile Creation**
- Locks the username of user to the their linked profile from the SPTvP Player Application
- Does not allow editing of profile nickname on profile creation
- Displays "SPTvP Username" instead of the usual other messages on the textbox such as "..taken", "..valid"...

**Game Settings**
- Locks the nickname to be the user's SPTvP username, does not allow edits
- Locks the "Change" button, not allowing any possible changes to be saved to the profile
